# 4-Week Sprint Plan: Zero to One

## Week 1: Research & Validation (De-risking)
* **Objective:** Validate the problem and secure verbal commitments before building.
* **Monday:** Draft user interview script and identify 15 cafes in Viman Nagar.
* **Tuesday-Wednesday:** Conduct 5 in-person interviews with cafe owners. 
* **Thursday:** Synthesize findings. Decide on final MVP feature set (Go/No-Go decision).
* **Friday:** Design the Tally.so mockups. Show them to 2 owners via WhatsApp for immediate feedback.

## Week 2: Build MVP (Execution)
* **Objective:** Build a functional, bug-free product using no-code tools.
* **Monday:** Set up Tally.so forms dynamically to accept URL parameters (Cafe_ID, Table_No).
* **Tuesday:** Set up Make.com automation logic (routing forms to Google Sheets).
* **Wednesday:** Integrate WhatsApp API (Interakt / Twilio) for the owner alert system.
* **Thursday:** End-to-end testing (scan to WhatsApp alert in < 5 seconds). Handle edge cases.
* **Friday:** Go to a local print shop and print 15 acrylic QR code standees.

## Week 3: Launch & Distribute (GTM)
* **Objective:** Acquire the first 3-5 active B2B users.
* **Monday-Tuesday:** Direct sales. Walk into 15 cafes, pitch the free 14-day trial, and leave standees on tables.
* **Wednesday:** Write and publish the first "Building in Public" LinkedIn post (framing it as a PM portfolio project).
* **Thursday-Friday:** Monitor backend logs. Ensure forms are being scanned. Debug any physical placement issues with owners via WhatsApp.

## Week 4: Measure & Iterate (Product Sense)
* **Objective:** Analyze data, gather user feedback, and iterate.
* **Monday:** Check Google Sheets dashboard. Calculate Day-7 retention and scan rates.
* **Tuesday:** Message the 5 cafe owners. Ask: "Did the WhatsApp alerts save any bad reviews this week?"
* **Wednesday:** Iterate the product based on feedback (e.g., make the text box optional to increase completion rates).
* **Thursday:** Draft the final Case Study / Portfolio Presentation.
* **Friday:** Publish the final teardown and results on LinkedIn; send cold DMs to hiring managers in Pune with the portfolio link.
